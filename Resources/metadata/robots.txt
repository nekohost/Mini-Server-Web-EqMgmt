# =============================================================================
# [파일명]       robots.txt
# [파일 경로]     Resources/metadata/robots.txt
# [파일 유형]     검색 엔진 로봇 배제 표준 설정 파일 (Robots Exclusion Protocol)
# =============================================================================
#
# [역할]
#   - Googlebot, Bingbot, Naver Yeti 등 웹 검색 엔진 크롤러 및 웹 스파이더에게
#     사이트 내 접근 허용(Allow) 및 차단(Disallow) 디렉토리 경로를 지시하는 정책 문서.
#   - app.py의 `/robots.txt` 라우트 엔드포인트를 통해 사이트 루트 레벨에서
#     text/plain MIME 타입으로 직접 제공됨.
#
# [의존성 관계]
#   - 상위 의존: 없음 (독립적인 정적 정책 텍스트 문서)
#   - 하위 피의존 (이 파일에 의존하는 요소):
#     · app.py -> serve_robots_txt() 라우트:
#       GET /robots.txt 요청 수신 시 `Resources/metadata/robots.txt`를 send_from_directory()로 응답
#     · 웹 검색 크롤러 / 봇: 사이트 탐색 전 가장 먼저 조회하여 인덱싱 제외 경로 준수
#
# [변경 시 영향도]
#   - 관리자 경로, 보안 인증 페이지, RESTful API 엔드포인트가 추가되거나 변경될 경우
#     본 파일의 Disallow 규칙을 갱신하여 민감 페이지의 외부 검색 엔진 노출을 방지해야 함.
#   - 파일 경로 변경 시 `app.py` 내 `serve_robots_txt()`의 `directory` 파라미터 동시 수정 필요.
#   - Rule.md 제4-5조(보안 및 환경 설정 수칙)에 의거하여 API 및 인증 페이지의 무분별한 색인을 방지함.
#
# [크롤링 정책 규칙별 상세 흐름]
# -----------------------------------------------------------------------------

# [대상 로봇 지정]
# 모든 웹 크롤러(Googlebot, Yeti, Bingbot, DuckDuckBot 등) 전체를 대상으로 일괄 정책 적용
User-agent: *

# [기본 인덱싱 허용]
# 사이트 루트(/) 및 일반 공개 리소스(정적 자산, 소개 등)에 대한 기본 접근 허용
Allow: /

# [관리자 센터 크롤링 차단]
# /admin_center 경로 차단 - 관리자 전용 대시보드 및 시스템 설정 페이지의 검색 노출 원천 차단
Disallow: /admin_center

# [백엔드 REST API 엔드포인트 크롤링 차단]
# /api/ 하위 전체 차단 - DB CRUD 및 세션 조작 비동기 API 엔드포인트에 대한 봇의 무의미한 호출 및 부하 방지
Disallow: /api/

# [로그인 페이지 크롤링 차단]
# /login 경로 차단 - 사용자 인증 페이지의 불필요한 검색 엔진 색인 및 브루트포스 봇 접근 억제
Disallow: /login

# [회원가입 페이지 크롤링 차단]
# /register 경로 차단 - 회원가입 양식 페이지의 검색 색인 방지 및 스팸 봇 자동 등록 시도 완화
Disallow: /register
