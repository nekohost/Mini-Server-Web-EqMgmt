- [x] 내부 요청만 관리하도록 동시성·대기·취소·재시작·실패 처리와 운영 조건 수정.
- [x] 기존 Strata 화면과 별개인 화면·메뉴·경로·자산 설계 반영.
- [x] 정정 검증 1: 거버넌스와 계획 범위.
- [x] 정정 검증 2: 사용자 의도.
- [x] 정정 검증 3: 내부 큐 논리·외부 혼잡·자체 요청 복구.
- [x] 정정 검증 4: 기존 화면/경로와의 독립성·운영 영향.
