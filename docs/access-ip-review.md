# 웹 접근 로그 AI 분석과 ipTIME 차단 등록

## AI 분석·TXT 추출

1. 관리자 계정으로 **웹 접근 로그 → 에러 유발 IP 분석**을 엽니다.
2. **AI 분석·TXT 추출**을 눌러 모델, 추론 수준, 분석 기간을 선택하고 **판단 시작**을 누릅니다. 검증된 공개 모델 중 Qwen3.8 Flash Next IQ3_S, IQ3_XXS 순으로 기본 선택합니다.
3. 완료 후 판정 근거를 확인하고 **차단 후보 TXT 다운로드**를 누릅니다. TXT에는 공인 IPv4 주소가 한 줄에 하나씩 들어갑니다.
4. 분석 창을 닫아도 서버 작업은 계속됩니다. **TXT 추출 이력**에서 자신의 완료된 분석을 열어 주소와 근거를 확인하고 TXT를 다시 받을 수 있습니다.

웹 앱 서비스 계정에는 Nginx의 기록과 순환 로그를 읽을 권한이 필요합니다. Flask와 Nginx의 출발지 IP, 시간, 경로, 메서드, 상태 코드가 일치한 오류 요청만 후보 산정에 사용합니다. 앱의 감사 로그에 로그인 성공 이력이 있는 주소와 비공인 주소는 후보에서 제외합니다. 모델에는 후보 번호와 공격 신호 건수만 전달합니다. 후보·판정 결과는 기존 AI 작업 저장소에 보관합니다.

## 공유기 브라우저에서 TXT 가져오기

1. Chrome 또는 Edge에서 ipTIME에 로그인한 뒤 **인터넷/WiFi 사용 제한** 화면을 엽니다.
2. 처음 한 번, 개발자 도구 **Sources → Snippets**에서 새 스니펫을 만들고 [iptime_firewall_import.js](../tools/iptime_firewall_import.js)의 내용을 저장합니다.
3. 로그인된 방화벽 탭에서 스니펫을 실행하고 추출한 TXT를 선택합니다.
4. 미리보기에 표시되는 신규·기존·확인 필요 주소를 확인한 뒤 **미리본 주소 차단 등록**을 누릅니다. 신규 규칙은 각 주소에서 들어오는 트래픽을 매일 24시간 차단합니다.
5. 등록 도구가 규칙 목록을 다시 조회해 동작 상태를 확인합니다. 등록이 중간에 끊기면 미리보기에서 TXT를 다시 선택해 남은 주소를 확인할 수 있습니다.

라우터 요청은 로그인된 탭에서 같은 출처의 `/cgi/service.cgi`로 전송합니다. 파일 선택 단계에서는 규칙 조회만 수행합니다. 적용 시 `firewall/add` 응답에 신규 규칙이 활성 상태로 나타나야 다음 주소를 처리합니다. 이 흐름은 단일 IPv4 규칙을 지원하는 ipTIME 방화벽을 대상으로 합니다.
