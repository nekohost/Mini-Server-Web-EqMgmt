최상위 포털의 상위 메뉴 생략, 기존 이전 이력/부모 경로, 검색 모드의 숨겨진 조건 제외, 카드3줄/가운데 배치, Edge의 넓은 표·카드 열 수는 유지했다. CSV 펼침은 UI만 변경하며 API 호출·검색·다운로드·미리보기 초기화·가져오기 확정을 발생시키지 않는다. 기존 모달/파일/명시 확정 흐름은 변경하지 않았다. Python·DB·권한·인증 변경은 없다.

기존 제안019·020·026의 개선으로 FEATURES.md/PROPOSALS.md에 기록했다. 별도 신규 제안이나 미구현 항목을 만들지 않았다.

## 검증

- 기존 회귀와 새 동작을 포함한 Node 검사 **44건 통과**. 실제 로컬 템플릿16종 × 6폭 × Standard/Edge로 상단 너비, 페이지 제목 폭(테두리 차이2px 이내), 가운데 좌표, 좌우 영역, 겹침/넘침을 비교했다. 기존8폭 검사와 카탈로그/제조사/설정/카드/검색 회귀도 유지했다.
- Windows에서는 Flask를 실행하지 않았다. Linux Jinja DictLoader의 읽기 전용 렌더링으로 로컬 후보 템플릿을 검사하고, 네트워크가 차단된 headless Edge fixture에서 JS는 필요한 모의 응답과 함께 실행했다.
- 기존 일반 사용자 guide_test_user로 실제 도메인에 로그인하여 **PC 중심37개 상태**를 통과했다. 배포 자산6개의 도메인 SHA, 설정 저장/새로고침·테마·프로필 창·Chart.js·기존 검색/이동을 검증했다. CSV 열기/가져오기 모달 열기/닫기 동안 장비 API 요청이0임을 확인했다. 파일 업로드나 가져오기 확정은 제출하지 않았다.
- **모바일 터치 에뮬레이션72개 상태 통과**: 두 스킨 × 포털·나의 장비·공개 장비·내 정보·통계 × 320×568/360×800/390×844/412×915의40상태, 상세검색16상태, CSV 펼침16상태. viewport배율1, 세로 방향, touch 활성/hover 비활성, 헤더 내부 배치 및 본문 분리, 좌/중앙/우 좌표, 가로 넘침을 확인했다. 320/390px 스크린샷도 육안 검토했다.
- 최종 서버5xx=0, 브라우저 pageerror=0. 일반 계정의 관리자 API는403 유지. 설정 복원·로그아웃 완료.

실기기, iOS Safari, 소프트키보드/시스템 글자 확대 검증은 아니다. 관리자 전용 페이지의 실계정 조작은 일반 사용자 권한 밖이므로 템플릿/정렬 검사와 배포 해시 확인 범위다. 터치 전용에서 카드 설명 native hover를 지원한다고 주장하지 않는다.

## 배포·복구 및 데이터 보존

- 14개 UI 파일의 배포 전 정규화 SHA·HEAD·정확한 PID/cwd/실행 명령을 확인했다. 기존 미커밋 변경에 무관한 전체 Git 정리/강제 덮어쓰기는 하지 않았다.
- 2026-09-14 **14:12:57 KST** 백업/배포. 기존 PID80368을 pidfd로 확인해 SIGTERM 종료하고 동일 인수/환경을 메모리에서 승계해 PID81107로 기동했다. 로그인 HTTP200, 배포 파일 해시 일치, 기동 오류 표식0을 확인했다.
- 복구 위치: `/home/nekohost/.local/share/mini-server-eqmgmt/releases/ui-header-csv-20260914T051257Z/`. 디렉터리0700, 파일/DB사본0600. before/candidate·DB 온라인 사본·manifest/result·기동 로그를 보존했다. 원자적 파일 교체 및 실패 시 이번 파일만 복구/재기동하는 보상 경로를 사용했으며 실제 롤백은 없었다.
- 배포 전 사본과 비교해 장비·옵션·노드의 모든 행, 사용자 식별 정보·역할·비밀번호가 동일하다. 전체 사용자의 유효 환경 설정도 원상 복원됐다. DB integrity=ok/FK위반0, 사용자3/장비1/옵션1/노드12 유지. 로그인/세션/접근 로그만 정상 부수 효과로 발생했다.
- 비밀번호는 기존 서버 보관본에서 테스트 프로세스 메모리로만 읽었으며 자격증명·쿠키 파일·trace는 만들지 않았다. 출력과 보고서에 비밀 값을 남기지 않았다.
