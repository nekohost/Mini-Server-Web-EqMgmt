## 1. 작업 범위

- Gemini가 `Staging/`에 구현한 Rule·거버넌스·문서 관리 도구를 정적으로 재검토했다.
- 발견한 결함을 스테이징에서 수정하고 전체 테스트와 실제 문서 복제 예행 연습을 수행했다.

## 2. 추가로 발견하고 수정한 결함

1. 존재하지 않는 달력 날짜와 일자별 999 초과 순번이 허용되던 문제를 차단했다.
2. `next --touch` 제목을 이용한 경로 이탈을 차단하고 신규 문서 필수 메타데이터를 자동 생성하도록 수정했다.
3. 마이그레이션 원장에 문서 종류·날짜·순번·정렬 근거·신뢰도를 기록하도록 보강했다.
4. 이동 후 경로표·인덱스·활성 문서 참조 갱신에서 실패해도 모두 복원하도록 롤백 범위를 확대했다.
5. 활성 문서의 과거 경로를 새 경로로 바꾸되 `Chat/`과 레거시 원본은 변경하지 않도록 했다.
6. 문서 종류별 파일명 접미사, KST 생성 시각, 관련 문서 경로, 경로표 수량과 레코드를 검증하도록 했다.
7. 보조 파일 복원 자체가 실패할 때 해당 오류가 누락되지 않고 치명적 롤백 오류로 보고되도록 했다.
8. 도움말에만 존재하고 실행되지 않던 `index` CLI를 구현하고, CLI 반환 코드가 실제 프로세스 종료 코드에 반영되도록 수정했다.
