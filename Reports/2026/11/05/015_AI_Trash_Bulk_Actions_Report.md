4. 운영 영향: 기존 단건 lifecycle 계약과 현재 대화 화면 처리를 유지한다. 단건 순차 호출/전용 API 선택은 구현 시 비교하며 지금 새 route·스키마를 확정하거나 추가하지 않는다. 전체 계정 자료나 장비 업무로 범위를 확대하지 않는다.
