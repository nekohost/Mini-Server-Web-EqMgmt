# 네 모델 비교 기준

문안과 채택 기준을 작성 세션 종료 후, 후보 응답이나 채점 결과를 열기 전에 고정했다. 작성 모델 네 개와 별도의 총괄 원문 대조를 진행한다.

개발 8편은 양방향 각 4편이다. 실제 운영에서 사용했던 합성 메일 두 편, 이전에 오류가 남은 메일, 정상 시나리오를 포함한다. 원문별로 기존 설정과 새 지침 네 개를 같은 260Strata에 각각 한 번 제출한다. 첫 응답, 오류, 저장 결과와 지연시간을 보존한다. 내용, 수신자, 서명 및 발송 준비성을 평가하며 참고 번역과 문자열이 다르다는 이유로 감점하지 않는다.

각 문안에서 1~5의 순서를 섞고 네 작성자와 대화 이력을 공유하지 않는 새 CLI 세션에 익명화된 Qwen 사용자 표시문만 제공한다. A는 필수 수정 없이 발송 가능, B는 필수 수정 필요, C는 본질적 의미 손실·오답·미완결이다. 동급 후보에는 공동 1위를 허용한다. 총괄은 매핑을 개봉하기 전 원문과 대조한다. 동일한 등급의 자연스러운 표현 차이는 오류로 세지 않는다.

방향별로 실제 중대 의미 오류와 A 건수를 우선한다. 평가자 또는 총괄 간 이견 중 채택 여부에 영향을 주는 것은 원문과 관련 후보만 새 별칭·순서로 제공해 네 명 모두 재평가한다. 다수결로 의미 오류를 상쇄하지 않는다. 검증 결과가 동등하면 운영 구성을 유지한다. 학습 문안 외 성능과 특정 거래·소유 업무에 한정한 효과는 분리해서 보고한다.

결정에 쓰지 않은 합성 6편과 기존 Hermes 시험 20편을 이후 확인한다. 확인용 자료에 새 C가 생기거나 발송 가능 비율이 낮아지는 방향은 그대로 전면 채택하지 않는다. 원문·메시지별 운영 지침이 완전히 동일한 과거 결과를 재사용하면 실측 시점과 재생 검증을 구분한다. 추가 모델 호출이나 외부 채점기는 제품 요청 경로에 넣지 않는다.
