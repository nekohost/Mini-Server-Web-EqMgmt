## 실측 품질

원래 장애 문안 2개와 별도 반례 10개를 동일 모델에서 순차 비교했다. A는 필수 수정 없이 발송 가능, B는 의미가 대체로 보존됐으나 수정 필요, C는 중요한 의미 오류·불완전 응답 등을 뜻한다. 아래는 각 번역문 전체를 원문과 대조한 판정이다. 두 Gemini의 발췌 평가는 위에 따로 기록했다.

| 방향 | 문안 | 기존 A / B / C | 개선 A / B / C | 기존 → 개선 응답시간 중앙값 |
|---|---:|---|---|---|
| 영→한 | 7 | 2 / 5 / 0 | 5 / 2 / 0 | 15.96초 → 38.97초 |
| 한→영 | 5 | 2 / 3 / 0 | 4 / 1 / 0 | 11.84초 → 11.33초 |
| 합계 | 12 | 4 / 8 / 0 | 9 / 3 / 0 | 방향별 집계 |

두 승인 미접수, 한 건 접수·한 건 대기, 0건 또는 1건인지 미확인, 두 건이 서로 다른 시각에 접수된 경우를 구분했다. 중간 후보는 한 건 대기 중이라는 문장에 ‘한 번에’를 넣었다. 수량과 동시성의 의미를 분리한 뒤, 해당 문안과 시각·미확인 반례를 실제 모델로 다시 확인했다. 한→영에서는 한글 이름의 영문 철자 추정, 병기 서명, 공동 서명과 서명 없는 메일을 확인했다. 기존 한→영의 이번 재측정은 `Yerin`이었고, 이전 운영에서 관측한 출력은 `Yerim`이었다.

발송 전 필수 수정이 남은 세 문안은 E2(두 번째 요청을 열람하지 않았다는 뜻을 처리 미착수로 넓힘), E4(승인 여부를 모른다는 한글 문장), K3(공동 서명 문안에서 회신 대상을 `me`로 좁힘)이다. 12개 합성 메일 결과로 다른 문안이나 다른 모델의 발송 품질을 보증할 수 없다. [문안별 판정과 근거](002_AI_Mail_Fidelity/quality.json) · [중간 후보를 포함한 실측 원문·출력·시간](002_AI_Mail_Fidelity/observations.json)
