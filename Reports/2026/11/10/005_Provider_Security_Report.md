## 운영 반영 및 중단 복구

2026년 11월 10일 22시 15분(한국 시각)에 웹과 AI 워커에 `1a342112`를 배포했다. 전환에 24.17초가 걸렸다. 중단 당시 Windows 준비본과 Linux staging의 변경 파일 55개를 대조하고 저장된 화면 캡처와 TLS 시험 기록을 확인했다. 전환 직전 업무 DB와 AI DB, 환경 설정, 이전 실행 환경을 운영 서버의 접근 제한 디렉터리에 보존했다. [전환 기록](005_Provider_Security/activation.json)

## 과거 로그인 감사 기록

배포 전 로그인 POST 834건 중 123건의 JSON 요청에 마스킹되지 않은 형태의 `Password` 값이 있었다. 건수는 요청 단위다. 이번 검사에서 제3자가 해당 값을 조회했다는 증거는 확인되지 않았다. 새 운영 로그인에서는 감사 이벤트를 남기면서 제출한 비밀번호가 저장되지 않는 것을 확인했다. 기존 기록은 운영 코드의 감사 상세 화면에서 요청·응답 본문이 모두 숨겨진다. 접근이 허용된 관리자 경로를 동일 코드로 시험하고 실제 과거 행을 읽기 전용 사본으로 한 번 더 확인했다. [집계](005_Provider_Security/historical-audit-counts.json) · [과거 행 검사](005_Provider_Security/historical-detail.json)

기존 DB와 백업 원본에는 과거 값이 남아 있다. 운영자는 해당 기간의 DB·백업 접근자를 검토하고 당시 사용한 비밀번호 중 계속 사용하는 것을 교체해야 한다. 기존 감사 기록을 지우거나 사용자 계정의 비밀번호를 일괄 변경하지 않았다.
