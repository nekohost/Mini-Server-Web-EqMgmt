# Hermes 세션·사용자 지정 연결과 006 계획 비교

## 판단

**핵심 사용 방식은 부합한다. 다만 Hermes 수준의 세부 설정까지 모두 명세한 계획은 아니므로, 기존 006을 유지하면서 일부 상세 계약을 보완하는 것이 맞다.** 현재 질문은 비교 판단이며 이번에 구현·006 원문 수정·Staging 반영은 하지 않는다.

Hermes의 공식 문서는 이름을 둔 custom provider, 주소/인증/모델 설정과 세션 내 모델 전환을 설명한다. 세션 문서는 대화 이력과 모델 설정의 저장·재개를 설명한다. 설치된 Hermes 문서 및 `hermes_cli/cli_model_switch_mixin.py:52`의 `stored_session_route`도 저장된 모델/provider/주소/API 방식을 복원하는 경로를 갖는다. 개인 설정·API 키·실제 세션 DB는 읽지 않았다. 참고: [프로바이더 문서](https://hermes-agent.nousresearch.com/docs/integrations/providers/#named-custom-providers), [세션 문서](https://hermes-agent.nousresearch.com/docs/user-guide/sessions/).

## 구현 전에 구체화할 상세 계약

1. **세션 복원:** 저장한 마지막 유효 선택과 추론값을 복원한다. 관리자의 새 대화 기본값보다 기존 세션 선택을 우선하고 다른 사용자/다른 세션에 전파하지 않는다. 선택이 폐기되면 마지막 선택을 표시하며 재선택을 안내한다. 다른 모델로 자동 교체하지 않는다. 과거 답변의 실제 모델 출처는 별도로 유지한다.
2. **수동 모델 등록:** 목록 API를 사용할 수 없을 때 관리자에게 upstream model ID·사용자용 별칭·기본 모델을 등록하는 경로를 제공한다. ‘수동 등록’과 ‘연결/기능 검증 완료’를 구분하며, 도구 지원을 자동 승인하지 않는다. 모델 목록 미지원만으로 endpoint 전체를 배제하지 않는다.
3. **요청 규약:** 관리자 화면의 ‘API 방식’을 명시하고 1차 지원은 OpenAI 호환 Chat Completions로 정한다. Responses/Anthropic Messages/native 규약은 별도 adapter가 구현·검증된 경우에만 선택 가능하게 한다. URL 문자열만 보고 지원 프로토콜을 무조건 추측하지 않는다.
4. **고급 옵션:** 관리자용 허용 목록으로 제한한 추가 헤더·생성 옵션·추론/템플릿 옵션을 제공하는 방향이 적절하다. provider B로 전환하면 provider A의 헤더·옵션·주소·키를 계승하지 않는다. 기존의 불변 revision 스냅샷으로 진행 요청에 적용한다.
5. **권한 필드 보호:** 추가 옵션으로 사용자/역할·messages/system·도구 allowlist·실행 승인·경로·인증정보·소유권을 덮어쓰지 못하게 한다. 인증 헤더는 비밀 관리 경로를 사용하고 로그 원문 보호도 유지한다. 커스터마이징을 임의 코드 실행·키 생성 셸 명령·TLS 검증 해제로 확장하지 않는다.

이 항목들은 비교에서 발견한 **보완 권고**다. 이번 보고서 작성이 006 변경이나 새 기능 구현 완료를 뜻하지 않는다. 기존 업무 범위·중복 실행 방지·장비관리 내부 큐 제한은 유지한다.

## 교차 확인과 최종 결론

- ‘PC A의 모델로 장비 등록 정보를 모음 → 같은 대화에서 PC B 선택 → 남은 정보를 계속 확인’은 006의 목표에 부합한다. 현 요청은 기존 모델에 고정하고 이후 요청부터 새 연결을 적용한다.
- ‘브라우저를 닫고 세션을 다시 열어도 마지막 연결·모델·추론값을 복원’은 기존 저장 설계를 바탕으로 **복원 우선순위와 연결 소멸 처리까지 명세**해야 한다.
- ‘Chat API는 있으나 모델 목록 API는 없는 사용자 지정 서버’는 자동 조회만 강제하지 말고 관리자 수동 모델 ID/별칭 등록으로 지원할 수 있어야 한다.
- ‘연결 A의 고급 헤더/추론 옵션이 연결 B에 그대로 남음’은 금지해야 한다. 설정은 연결별로 저장·적용·초기화하며 사용자 업무 권한을 덮어쓸 수 없어야 한다.

기존 확장 판단을 뒤집거나 전면 재작성할 근거는 없다. **006의 핵심 방향은 유지하고, 세션 복원·수동 모델 등록·endpoint 고급 설정의 세 가지 상세를 보완할 필요가 있다.** 세션 이름 변경/검색/분기와 Hermes 범용 도구 전체는 현재 계획에 포함됐다고 말할 수 없으며 별도 범위다. 상세 보완 권고는 이 보고서에 남겼고 원래 계획/평가 중 후보는 그대로 보존했다.
