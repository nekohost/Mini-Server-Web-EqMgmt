# 제안과 로드맵

신규 기능 제안은 원본 보존 문서 `PROPOSALS.md`와 현재 미구현 추적 문서 `UNIMPLEMENTED_PROPOSALS.md`에 함께 기록한다.

채택·승인된 개발 항목은 이력을 위해 `ROADMAP.md`에 등록하고 작업 대기열인 `UNIMPLEMENTED_ROADMAP.md`에도 함께 등록한다. 단순 질문이나 아직 기능 제안으로 확정되지 않은 대화까지 자동 등록하지 않는다.
