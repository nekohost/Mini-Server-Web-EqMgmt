# 프로젝트 문맥

이 저장소는 개인 보유 장비와 자산을 등록·관리하는 Flask 기반 웹 애플리케이션이다. Python Flask 백엔드와 REST API를 학습하고 실제 미니서버에서 운영하는 목적을 함께 가진다.

모든 코드 변경은 상세 설명 주석과 의존성 파급 안내를 포함해야 한다. 함수와 API의 메타 주석 및 행 단위 설명의 구체적 요구는 `engineering.code-comments`를 따른다.
