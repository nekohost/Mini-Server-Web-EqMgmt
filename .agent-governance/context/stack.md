# 기술 스택

- Backend: Python 3, Flask, REST API
- Database: SQLite3 `equipment.db`
- PC DB GUI: DBeaver
- Frontend: HTML5, Vanilla JavaScript, Tailwind CSS CDN

외부 의존성은 필요할 때 사용할 수 있다. 외부 의존성을 제안하거나 추가할 때에는 그 필요성·비용·운영 영향을 설명하고, 사용하지 않고 구현 가능한 대안도 동시에 제시한다.
