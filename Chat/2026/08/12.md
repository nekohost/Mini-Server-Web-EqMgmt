본 가이드는 Microsoft Graph API(OAuth 2.0 Client Credentials Flow)를 통해 백그라운드 메일 발송 유틸리티가 작동할 수 있도록 M365 테넌트에 앱을 등록하고 필요한 값들을 추출하는 과정입니다.

#### 1단계: Microsoft Entra 관리 센터 접속 및 앱 생성
1. 브라우저에서 **[Microsoft Entra 관리 센터](https://entra.microsoft.com)**에 관리자(전역 관리자 또는 애플리케이션 관리자) 계정으로 로그인합니다.
2. 좌측 메뉴에서 **Identity (ID)** ➔ **Applications (애플리케이션)** ➔ **App registrations (앱 등록)** 메뉴를 클릭합니다.
3. 상단의 **+ New registration (+ 신규 등록)** 버튼을 클릭합니다.
4. 등록 페이지에서 아래와 같이 입력 후 하단의 **Register (등록)** 버튼을 누릅니다:
   - **Name (이름):** `Mini-Server-Web-EqMgmt-Mailer` (시스템 식별용 명칭)
   - **Supported account types (지원되는 계정 유형):** `Accounts in this organizational directory only (Single tenant)` (이 조직 디렉터리의 계정만 - 단일 테넌트) 선택
   - **Redirect URI (리디렉션 URI):** 백그라운드 서비스이므로 설정하지 않고 비워둠

#### 2단계: 필수 식별 ID (테넌트 ID, 클라이언트 ID) 수집
1. 앱 등록 완료 후 자동으로 이동하는 **Overview (개요)** 페이지를 확인합니다.
2. 다음 두 가지 값을 복사하여 보관합니다:
   - **Application (client) ID (애플리케이션(클라이언트) ID):** `.env`의 `MS_CLIENT_ID`
   - **Directory (tenant) ID (디렉터리(테넌트) ID):** `.env`의 `MS_TENANT_ID`

#### 3단계: 클라이언트 암호 (Client Secret) 생성
1. 좌측 메뉴의 **Certificates & secrets (인증서 및 암호)** ➔ **Client secrets (클라이언트 암호)** 탭을 선택합니다.
2. **+ New client secret (+ 새 클라이언트 암호)** 버튼을 클릭합니다.
3. **Description (설명):** `EqMgmt Mailer Key` 입력 / **Expires (만료):** 원하는 기간(예: 180일 또는 12개월) 선택 후 **Add (추가)** 버튼을 누릅니다.
4. **⚠️ [매우 중요]** 생성 직후 표에 표시되는 **Value (값)** 컬럼의 텍스트를 즉시 복사합니다.
   - *주의: 이 값은 창을 벗어나면 다시는 열람할 수 없으므로 생성 즉시 복사해야 합니다.* ➔ `.env`의 `MS_CLIENT_SECRET`

#### 4단계: API 권한 부여 (Microsoft Graph Mail.Send)
1. 좌측 메뉴에서 **API permissions (API 권한)**을 선택합니다.
2. **+ Add a permission (+ 권한 추가)** 버튼을 클릭합니다.
3. 요청 팝업에서 **Microsoft Graph** ➔ **Application permissions (애플리케이션 권한)**을 선택합니다. *(Delegated/위임 권한이 아님에 유의)*
4. 검색창에 `Mail` 입력 ➔ `Mail` 그룹을 확장 ➔ **`Mail.Send`** 체크박스에 체크합니다.
5. 하단의 **Add permissions (권한 추가)** 버튼을 클릭합니다.

#### 5단계: 관리자 동의 부여 (Admin Consent)
1. 권한 목록에 `Mail.Send`가 추가된 것을 확인합니다. (상태가 "Not granted for..." 로 표시됨)
2. 권한 테이블 상단의 **Grant admin consent for <테넌트명> (<테넌트명>에 대한 관리자 동의 허용)** 버튼을 클릭합니다.
3. 확인 팝업창에서 **Yes (예)**를 클릭합니다.
4. 상태가 초록색 체크 아이콘과 함께 **Granted for <테넌트명> (승인됨)**으로 변경되었는지 최종 확인합니다.

---

#### 💡 최종 수집된 정보 점검 (`.env` 세팅 준비)
위 단계를 완료하면 시스템에 세팅할 아래 4가지 핵심 환경변수 값이 확보됩니다:
```env
MS_TENANT_ID=xxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
MS_CLIENT_ID=xxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
MS_CLIENT_SECRET=your_secret_value_here
MAIL_SENDER_ADDRESS=admin@yourdomain.com
```

안내해 드린 절차를 통해 Azure Entra ID 상에서의 준비가 완료되면 언제든 백엔드 모듈 연동 작업을 지시해 주십시오!
