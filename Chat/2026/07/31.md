## Gemini 2026-07-31 10:22:00.000

SQLite 데이터베이스(우리의 경우 `equipment.db`)에 접속하여 `users` 테이블에 있는 사용자 정보를 쿼리(조회)하는 방법은 아주 간단합니다!

미니서버 터미널에서 다음 순서대로 진행하시면 됩니다.

### 1. SQLite 콘솔 접속하기
앱 폴더(`Mini-Server-Web-EqMgmt`) 위치에서 아래 명령어를 입력하여 DB 파일에 접속합니다.
```bash
sqlite3 equipment.db
```
접속에 성공하면 프롬프트가 `sqlite>` 모양으로 바뀝니다.

### 2. 가독성을 높이는 설정 (선택 사항이지만 강력 추천)
데이터를 표(Table) 모양으로 예쁘게 보기 위해 접속 직후 아래 두 명령어를 먼저 치는 것이 좋습니다.
```sql
.mode column
.headers on
```

### 3. 사용자 정보 쿼리하기 (SQL 입력)

**A. 모든 사용자 정보 한눈에 보기**
```sql
SELECT * FROM users;
```

**B. 비밀번호(해시)를 제외하고 깔끔하게 필요한 정보만 보기**
```sql
SELECT UserId, LoginId, UserName, Role, CreatedAt FROM users;
```

**C. 특정 사용자(예: 'nekohost')만 검색하기**
```sql
SELECT * FROM users WHERE LoginId = 'nekohost';
```

### 4. 빠져나오기
조회가 모두 끝났다면 아래 명령어로 SQLite 셸을 종료하고 원래 리눅스 터미널로 돌아갑니다.
```sql
.quit
```
