#                               (SECRET_KEY, FLASK_DEBUG, DB 경로, 메일 설정 등)

#     · utils/mailer.py       : requests → Microsoft Graph API OAuth 2.0 토큰 요청

#                               (POST https://graph.microsoft.com/v1.0/users/.../sendMail)

# [변경 시 영향도]

#   - 패키지 제거 시: 해당 패키지를 import하는 모든 Python 모듈에서 ImportError 발생.

# --- python-dotenv -----------------------------------------------------------
# [역할] .env 파일에서 환경변수를 읽어 os.environ에 주입하는 라이브러리.
# [사용처] app.py 최상단 `from dotenv import load_dotenv` → `load_dotenv()` 호출.
# [로딩 대상 환경변수 (.env 파일 내)]
#   · SECRET_KEY          : Flask 세션 암호화 키 (Rule.md 제4-5-1조 하드코딩 금지)
#   · FLASK_DEBUG         : 디버그 모드 on/off (Rule.md 제4-5-2조 환경변수 제어)
#   · DATABASE_PATH       : SQLite3 DB 파일 경로 (equipment.db)
#   · SESSION_LIFETIME    : 세션 만료 시간(분)
#   · MAIL_TENANT_ID      : Microsoft 365 Azure AD 테넌트 ID
#   · MAIL_CLIENT_ID      : Azure AD 앱 등록 클라이언트 ID
#   · MAIL_CLIENT_SECRET  : Azure AD 앱 클라이언트 시크릿 (민감 정보)
#   · MAIL_SENDER         : 발신자 이메일 주소
# [의존성] 이 패키지가 없으면 load_dotenv() 실패 → 환경변수 미로딩 → 앱 기동 불가.
python-dotenv

# --- requests ----------------------------------------------------------------
# [역할] HTTP 클라이언트 라이브러리. RESTful API 호출을 간결하게 수행.
# [사용처] utils/mailer.py 내 2개 HTTP 요청:
#   1. OAuth 2.0 토큰 취득: requests.post(token_url, data=token_data)
#      → Microsoft login.microsoftonline.com에 client_credentials 그랜트 요청
#      → 응답 JSON에서 access_token 추출
#   2. 메일 발송: requests.post(send_url, headers=headers, json=email_message)
#      → Microsoft Graph API v1.0 sendMail 엔드포인트 호출
#      → Bearer 토큰 인증 헤더 탑재
# [의존성] 이 패키지가 없으면 메일 발송 기능 전체 불가 (ImportError: No module named 'requests').
# [참고] requests는 내부적으로 urllib3, certifi, charset-normalizer, idna를 추가 설치함.
requests
