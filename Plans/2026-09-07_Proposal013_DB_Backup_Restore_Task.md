# [Task] 제안-013 데이터베이스 백업·복원

## 작업 모드와 범위

- 모드: 구현계획 및 사전 검증
- 승인 범위: 계획 문서와 검증 보고서 작성. 애플리케이션, 운영 DB, 배포 설정은 변경하지 않는다.
- 대상: `app.py`, 신규 `templates/backup_restore.html`, 메뉴·권한 초기화 경로, 배포 절차 및 문서 동기화
- 제외: 운영 DB 열람, 실제 백업·복원, 서비스 중지, 운영 병합 및 원격 반영

## 순차 Task

1. 현재 코드의 DB 연결, 비동기 접근 로그 워커, 인증·CSRF·메뉴 구조를 정적으로 확인한다. 완료.
2. 백업 및 복원의 분리된 운영 모델과 보안 경계를 설계한다. 완료.
3. 검증 1~8단계를 수행하고 차단 조건을 기록한다. 완료.
4. 선행 제안-046 점검 모드를 먼저 구현·검증한 뒤 Staging에서 무중지 온라인 백업·복원을 구현한다.
5. 모의 DB로 DB 쓰기 동결, 온라인 복원, 실패 시 자동 원복을 검증한다.
6. Staging 정적 검증, 서버 검증, 운영 병합 검토를 순차적으로 수행한다.
