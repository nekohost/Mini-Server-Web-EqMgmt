# app.py 인코딩·문법 복구 계획

## 원인

`app.py` 376행의 한글 주석 문자열 끝에 UTF-8로 완성되지 않은 바이트 `0xEC`가 있다. 같은 지점에서 `init_db()` docstring의 닫는 `"""`도 누락되어, 비 UTF-8 오류를 통과하더라도 다음 문법 오류가 발생할 수 있다.

## 복구 범위

1. 파일 첫 줄에 UTF-8 인코딩 선언을 둔다.
2. `init_db()`의 손상된 docstring을 역할·의존성·변경 영향이 포함된 유효한 docstring으로 교체한다.
3. `migrate_access_logs_menu()`의 정상 호출 뒤에 잘못 삽입된 중복 함수 꼬리와 `init_db()` 테이블 정의 조각을 제거한다.
4. 정상 테이블 정의와 실행 로직은 변경하지 않는다.

## 검증

- 전체 바이트가 유효한 UTF-8인지 확인한다.
- 접근 로그 메뉴 마이그레이션 호출이 한 번만 존재하는지 확인한다.
- `python -m py_compile app.py`로 실행 없이 문법을 확인한다.
- 변경 diff와 Git 상태로 범위를 확인한다.

## 롤백

이 변경은 Git diff로 확인·되돌릴 수 있으며 DB·서버 프로세스·배포 상태에는 직접 변경을 가하지 않는다.
