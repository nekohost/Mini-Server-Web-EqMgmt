# 웹 접근 로그·AI 기록 분리 운영 반영

work_id: 20261112-003-access-log-production

사용자가 검증한 11월 12일 Staging ZIP과 현재 운영 코드를 대조한다. 배포 대상은 웹 로그 수집, 관리자 정리 화면·API와 관련 문서·시험이다. 기존 웹 로그, AI 업무 기록, 구형 미전송 파일과 사용자가 보유한 변경을 보존한다.

1. 릴리스 지문과 소스 차이를 독립 대조하고 실제 Codex CLI 작업자 설정·사용량을 기록한다.
2. 운영 서버의 서비스·작업·저장 공간을 확인한다. 서버 안의 접근 제한 디렉터리에 원본 소스 참조와 SQLite 일관 사본을 확보하고 사본의 무결성을 확인한다.
3. 두 삭제 방식은 격리 사본에서 실행한다. 정리 시작 전에 있던 AI·일반 행과 그 뒤의 새 접근, 장비와 AI 원본의 보존 범위를 확인한다.
4. 승인된 소스만 병합·정적 재검증한 커밋을 배포한다. 이전·새 웹 워커의 쓰기가 겹치지 않게 교체하고 웹·AI 워커의 실제 상태를 확인한다.
5. 운영의 기존 로그를 배포 기준 시점과 대조하고 일반 시험 계정으로 AI 요청 1건의 응답·재열람 및 웹 로그의 본문 미수집을 확인한다. 운영 자료는 서버에만 보관하며 보고서에는 집계·지문만 기록한다.
