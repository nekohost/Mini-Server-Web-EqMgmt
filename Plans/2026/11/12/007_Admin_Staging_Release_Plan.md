# 관리자 기능 통합 배포 계획

work_id: 20261112-007-admin-staging-release

회원 이름을 비우면 보안 감사 로그 행위자를 실제 로그인 ID로 표시한다. 이름이 있는 회원과 시스템 행위의 기존 표시도 확인한다. 웹 접근 로그 유휴 만료, 관리자용 AI 기록, 회원가입 이름 표기, 관리자 계정 생성의 검증된 세 패치를 같은 릴리스에 포함한다.

1. 확장 컨텍스트 CLI 작업자 한 명은 구현·회귀를, 한 명은 독립 검증을 맡는다.
2. 합성 Linux DB로 기존 결함을 재현하고 통합 후보와 실제 Git 배포 파일을 대조한다.
3. 운영 호스트·버전, 실제 로그 삭제의 진행 여부, 최근 쓰기 및 복구 수단을 확인한다. 사용자 데이터는 온라인 백업하고 진행 중인 요청을 보호한 후 웹을 전환한다.
4. 운영 HTTPS에서 가입 화면과 관리자 메뉴·감사 행위자의 실제 동작을 확인한다. 260Strata를 사용하지 않는 조회 경로로 AI 기록을 검증한다. 시험 데이터를 운영에 영구 추가할 필요가 있는지는 기존 데이터로 먼저 확인한다.
