# AI 도우미 메일 번역 운영 반영

검증된 016번 번역 개선을 일반 사용자의 장비관리 AI 도우미에서 제공한다. 실제 운영 기준 커밋과 013 번역 담당 인계, 016 최종 지시·표시 소스를 대조해 번역 경로와 필요한 검사만 배포한다.

1. 운영이 사용하는 소스와 두 데이터베이스, 모델 연결, 웹·워커, 기존 작업을 확인한다. 운영 기준 묶음에 포함된 독립적인 관리자용 CA 설정과 보안 후보는 별도 작업으로 보존한다.
2. 정확한 배포 후보에서 일반 대화·다른 공급자·구형 작업·통신 오류·전송 중복·번역 응답·화면 표시를 격리 Linux에서 확인한다. 실제 데이터의 일관 사본으로 기존 업무와 AI 행 보존을 확인한다.
3. 승인된 파일만 Git 운영 브랜치에 올리고 배포한다. 원본 코드와 설정 및 DB의 비공개 복구 자료를 준비하고, 대기·실행·종료 불명 작업이 없을 때만 웹과 워커를 전환한다. 정상 실행 중인 요청은 마칠 때까지 기다린다.
4. 실제 운영 도메인의 일반 사용자 대화에서 합성 메일을 방향별로 한 번씩 순차 전송한다. 모델·추론 수준과 작업 종료, 실제 표시와 재열기, 기존 기록 및 운영 상태를 확인한다. 실측과 남은 한계를 별도로 기록한다.
