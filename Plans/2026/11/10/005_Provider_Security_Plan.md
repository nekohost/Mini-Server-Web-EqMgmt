# AI 프로바이더 연결과 보안 패치 운영 반영

작업 ID는 PROVIDER-SECURITY-20261110이다. 운영 중인 번역과 장비 업무를 유지하며 이미 검토한 보안 수정과 관리자 연결 버전을 현재 운영 소스에 병합한다.

1. 기존 연결과 새 내부망 HTTP 연결을 웹·워커에서 검증한다. HTTPS의 기본은 시스템 신뢰이며, 사설 CA는 관리자가 연결별 공개 PEM을 등록한다. 사용자 단말의 인증서 설치는 요구하지 않는다.
2. 기존 보안 수정본을 현재 소스와 대조하고, DB 사본에서 기존 행·감사 데이터 보존과 기동을 확인한다. 민감한 환경값과 시험 원문은 공개 보고서에 복사하지 않는다.
3. Linux 격리 회귀 시험과 관리자 등록·HTTPS 오류·실제 내부망 모델 호환을 확인한다. 이전 설정과 두 DB의 백업을 확보한 뒤 웹과 워커를 같은 버전으로 전환하고 운영 응답을 확인한다.
