# 통계 복합 분포와 장비 화면 배치 시범

1. 같은 카테고리와 제조사를 고른 결과에 대해 기존 API가 반환하는 상태별 수량을 도넛과 수량표에 표시한다. 상단의 두 분포와 렌더 방식을 공유하고 기존 장비 목록은 펼쳐 확인한다. 0건·조회 실패·필터 변경·연속 조회에서 이전 결과가 남지 않아야 한다. DB, 범위 조건, 권한은 변경하지 않는다.
2. 포털은 상단 바의 제목 한 번으로 위치를 알리고 두 요약 카드와 메뉴를 바로 보여준다. 나의 장비는 검색·목록 작업부터 보여주며 임시저장함 전환 시 상단 제목도 바뀐다. 운영 메뉴 트리에는 나의 장비 바로 아래 별도 경로가 없다. 같은 화면에서 여는 등록/수정·상세·CSV·카탈로그 신청의 고유 제목과 폼을 보존하고 필요한 여백만 줄인다. 공개 장비는 공유 템플릿의 별도 분기로 기존 화면을 유지한다.
3. 후보를 Staging에 구현한다. 실제 템플릿과 브라우저로 PC/모바일, 라이트/다크와 Standard/Edge, 검색·상태 데이터·빈 결과·재검색·하위 화면 동선을 확인하고 화면 증거를 남긴다. 문제가 있으면 후보에서 수정한 뒤 영향을 받은 검사를 반복한다.
4. 확인한 후보와 원문을 보존해 root·Git·Linux로 반영한다. 백업/소스 대조 후 운영 일반 계정으로 조회와 화면 이동을 검증한다. 운영에서 시험 장비 등록·수정·삭제는 하지 않으며 다른 서비스는 제어하지 않는다.
