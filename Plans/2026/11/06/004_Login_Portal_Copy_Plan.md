# 로그인·포털 문구 정리

로그인 화면의 표시 제목을 `장비관리 시스템`으로 변경하고 같은 화면의 브라우저 제목도 `로그인 - 장비관리 시스템`으로 맞춘다. 메인 포털의 `이용 가능한 메뉴에서 장비와 정보를 확인하세요.` 문단은 제거한다. 다른 화면의 명칭, 포털 제목·메뉴·위젯, 로그인 폼과 인증 동작은 변경하지 않는다.

두 템플릿을 Staging에서 수정하고 Linux의 Jinja 렌더와 기존 포털 화면 검사를 사용한다. 문구 변경에 별도의 새 테스트를 추가하거나 AI 전체 회귀를 반복하지 않는다. 원문/SHA를 보존한 뒤 root 병합·정적 대조·정확한 후보 정리·한정 commit/push를 수행한다. 현재 백업·실제 DB 사본 보존 확인과 idle 자체 서비스 반영 후 운영 로그인/포털의 PC·모바일 화면과 실제 로그인을 확인한다. 기존 설정/업무/감사와 다른 작업자의 변경을 보존한다.
