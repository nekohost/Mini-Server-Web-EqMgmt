# 오래 열어 둔 로그인 화면 복구

work_id: 20261111-001-login-csrf

11월 11일 운영에서 로그인 화면을 받은 지 2시간 22분 26초 뒤의 로그인 요청이 CSRF 검사에서 거절되었다. 로그인 전 세션의 서명 유효시간은 30분이고, 기존 화면은 처음 받은 토큰을 계속 제출한다.

1. 사용자가 로그인을 누를 때 기존 `GET /login`에 JSON 형식으로 현재 세션의 폼 토큰을 요청한다. 유효한 토큰은 재사용하고 만료됐다면 기존 발급기를 사용한다. 일반 페이지 요청과 로그인된 사용자의 이동, 점검 정책을 유지한다.
2. 폼을 그대로 둔 채 같은 출처의 응답을 확인하고, 입력한 자격 증명은 한 번만 전송한다. 빠른 클릭과 Enter를 하나의 제출로 처리한다. 다른 탭의 로그인은 서버가 선택한 포털 또는 탈퇴 유예 화면으로 이어 간다.
3. 로그인에 실패하면 입력을 유지하고 다시 제출할 수 있게 한다. 네트워크 오류나 응답 유실 후 비밀번호를 자동으로 재전송하지 않는다. 세션 수명, CSRF 비교, 인증 시도 제한, 비밀번호 검증, 감사 기록의 본문 보호 기준을 유지한다.
4. 정적 검사 후 Linux 격리 환경에서 새 폼, 오래된 폼, 다른 탭, 중복 제출, 잘못된 비밀번호와 재시도, 통신 오류를 검증한다. 운영 병합은 검증 결과에 대한 승인을 기준으로 한다.
