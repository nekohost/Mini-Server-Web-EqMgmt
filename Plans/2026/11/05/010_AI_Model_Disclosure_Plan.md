# AI 모델 선택 영역 접기

사용자 승인 범위는 계획 후 현재 `Staging/20261105-ai-csv-popup`에 병합하는 것이다. 기존 CSV 팝업·화면 높이 측정·스크롤바 테마를 보존한다. 운영 소스/서버·DB·web_search는 이번 대상이 아니다.

1. 검토 완료된009의 통합 원문 ZIP/해시와 현재 overlay를 대조해 기준을 보존한다. 새 계획·Task·검증은010으로 남긴다.
2. 추론 select와 보내기 버튼은 현재 composer actions에 둔다. 모델 select와 목록 새로고침 버튼은 그 아래, 추론 단계 지원 안내 위에 있는 native `<details>`로 옮긴다. summary는 `AI 모델 선택`으로 하고 `open` 속성이나 저장된 펼침 설정 없이 기본 접힘으로 제공한다.
3. 기존 select/refresh ID·label·ARIA 연결·지원 단계 비활성화/모델 저장/새로고침 동작을 보존한다. details를 접어도 DOM을 제거하거나 선택값·초안을 초기화하지 않는다. 사용자가 펼친 상태는 polling/모델 변경/새로고침 때문에 강제로 닫히지 않는다.
4. 모델 연결 상태·오류 메시지는 접이식 영역 밖에 남겨 숨겨진 오류 때문에 보내기 불가 원인을 놓치지 않게 한다. 사용할 수 없는 모델/추론 지원 안내는 기존의 별도 접이식으로 유지한다.
5. 기존36px/모바일44px 제어 높이와136px 모델 select 최대 폭을 유지한다. 옮겨진 select에도 동일 스타일을 적용하고, 접힌 경우 모델/새로고침의 layout 공간을 없앤다. 기본 상태에서 추론 아래, 지원 안내 위 순서를 실제 좌표로 검증한다.
6. 기존 브라우저 회귀에서 모델 제어 크기/포커스 검사 시에만 명시적으로 펼친다. 기본 접힘, 실제 클릭 왕복, 공간 절약, 상태 보존·오류 노출·모바일 폭·실측 높이 및 CSV 팝업을 Linux 격리 Chromium에서 검사하고 대표 스크린샷을 검토한다. backend는 변경하지 않으며 기존 증거와 이번 검증을 구분한다.

구조화 편집으로 현재 Staging에만 변경한다. 복구는009 검토 원문에서 바뀐 template/CSS/검사 보조만 되돌리며 전체 저장소/운영 데이터는 건드리지 않는다. 새 UI 라이브러리나 네트워크 경로는 추가하지 않는다.
