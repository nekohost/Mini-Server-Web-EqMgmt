# 006 확장 계획의 구현 순서

006의 기능·보안·사용자 결정이 상세 명세다. 먼저 감사 훅과 lifecycle S01~S04를 수정한다. 다음 별도 AI DB v3에 연결/불변 revision/모델/자원 그룹/선택/업무 초안을 가산하고, 서버 전용 허용 목적지 transport와 Strata/OpenAI 호환 adapter를 연결한다. 관리자에서 기본 연결·비밀·모델 공개/검증을 관리하며 고급 custom headers/body 설정은 제공하지 않는다.

실행 전체에 선택 모델/연결 revision을 고정하고 그룹별 슬롯을 짧은 transaction으로 선점한다. worker dispatcher는 여러 독립 그룹을 처리하되 같은 그룹의 종료 불명확 요청은 잠금을 유지한다. 장비관리 요청만 제어한다. 신규·기존 대화의 선택과 지원 추론을 복원하고, 소유자별 정규화 초안·원문 참조·서버 영수증을 한도 안에서 인계한다. 사용자가 확인한 기존 카드 실행 계약과 일반 사용자 권한은 유지한다.

검증은 기존 fixture를 확장해 관리자 권한/SSRF/키 비노출/멱등 충돌/설정 revision 고정/동일·상이 그룹 경쟁/종료 불명확/점검/준비 예외/최초 사유/선택 복원/업무 인계/저장 한도/실제 browser 흐름을 확인한다. 실서버 두 곳의 설치·API·모델 품질 검증을 합성 시험으로 대신했다고 주장하지 않는다. 운영 병합 전에는 별도 사용자 검토가 필요하다.
