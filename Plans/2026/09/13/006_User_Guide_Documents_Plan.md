# 일반 사용자 가이드 제작 계획

## 산출물과 범위

운영 중인 `https://nekohost.org`에 일반 사용자 테스트 계정으로 접속하여 Markdown 사용 가이드와 PowerPoint를 `docs/user-guide/`에 만든다. 실제 화면과 버튼의 의미·입력 순서·주의사항을 기록한다. 관리자 전용 화면은 범위 밖이다. 테스트 계정에 없는 소유 장비 때문에 실행하지 못한 작업은 확인된 UI·소스 근거와 실수행 여부를 구분한다.

## 실행 계약

- 브라우저에서 실제 화면을 관찰하고 원본 스크린샷을 저장한다. 임의로 UI를 합성하지 않는다.
- 로그인 비밀번호는 백업 서버 전용 파일에서 메모리로 읽고 출력·문서·Git에 포함하지 않는다.
- 실제 장비 생성·수정·삭제, 이메일 발송·비밀번호 변경·회원 탈퇴는 실행하지 않는다. 모달 열기와 취소·검색·탭 전환은 허용 범위다.
- 기존 소스·DB 스키마·배포 상태는 변경하지 않는다. 문서 제작물과 작업 기록만 추가한다.
- Markdown은 저장소에서 바로 읽을 수 있고, PPT는 실제 화면과 편집 가능한 한국어 설명을 함께 배치한다. PPT 전체 슬라이드를 이미지로 렌더링하여 검수한다.

## Validation 1→8

1. 규칙: 승인된 문서 제작·외부 읽기·인증 범위이며 Task를 선행 작성했다. 코드 배포/Staging은 해당 없음.
2. 의도: 테스트 계정의 실화면을 기반으로 처음 사용하는 사람의 메뉴·버튼 이해와 기본 작업 흐름을 지원한다.
3. 정적 논리: 각 화면과 설명의 근거를 연결하고 실제 미수행 기능을 성공 검증으로 오인하지 않게 한다.
4. 운영 영향: 로그인·조회·모달 관찰에 한정한다. 업무 데이터 변동을 만들지 않는다.
5. 보안: 비밀번호·쿠키·토큰을 파일/대화에 기록하지 않는다. 불필요한 타 사용자 상세 개인정보 캡처는 피한다.
6. 복구: 신규 문서·이미지·PPT만 제거하면 되며 기존 파일은 덮어쓰지 않는다. 세션은 마지막에 로그아웃한다.
7. 휴먼 에러: 위험 버튼은 기능과 주의만 설명하고 누르지 않는다. 이메일 미설정 테스트 계정의 제한을 명시한다.
8. AI 메타: 캡처일·운영 주소·권한·실제 실행 여부·문서 검수 결과를 보고서에 구분 기록한다.

판정: 문서 제작 진행 가능. 추가 운영 데이터 변경이 필요하면 이 계획의 범위로 실행하지 않는다.
