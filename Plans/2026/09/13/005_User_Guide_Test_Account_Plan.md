# 사용 가이드용 일반 사용자 테스트 계정 생성 계획

## 목적

현재 운영 대상인 백업 서버에 이메일 인증을 요구하지 않는 일반 사용자 테스트 계정 `guide_test_user`를 수동 생성한다. 이 계정은 `nekohost.org` 사용자 화면의 사용 가이드 작성과 권한 차이 확인에 사용한다.

## 실행 계약

- 실제 DB는 `/home/nekohost/services/Mini-Server-Web-EqMgmt/equipment.db`다.
- 계정은 `Role='user'`, 활성·미삭제 상태, 이메일·인증 이메일 NULL로 생성한다.
- 비밀번호는 서버에서 암호학적으로 임의 생성하고 Werkzeug 해시만 DB에 저장한다.
- 평문 자격증명은 Git과 대화 기록에 넣지 않는다. 백업 서버의 사용자 전용 디렉터리에 0600 파일로 보관한다.
- 변경 전 SQLite 온라인 백업을 0600으로 만들고, 계정 삽입과 감사 로그 기록은 한 트랜잭션에서 수행한다.
- 같은 LoginId가 이미 있으면 덮어쓰거나 재설정하지 않고 실패한다.

## 검증과 복구

- DB 무결성·외래키, 역할·활성 상태, 비밀번호 해시 검증, 일반 사용자 허용 메뉴 수를 확인한다.
- 계정은 이메일 복구·기한 알림 기능을 사용할 수 없다. 일반 사용자 UI/권한 문서화에는 영향이 없다.
- 사용 전 복구는 생성한 UserId의 참조가 없음을 확인한 뒤 해당 계정과 생성 감사 행만 제거한다. 사용 후에는 생성 데이터가 연결될 수 있으므로 계정 삭제 API 또는 별도 정리 계획을 따른다.
